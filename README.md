# 🗺️ Interactive Middle-earth Map

An interactive web-based map of Middle-earth inspired by *The Lord of the Rings*. Explore iconic locations across Arda, filter by region or category (The Fellowship, Dark Lands, Realms of Elves, etc.), track the Fellowship's journey, and dive into lore with immersive modals.

## ✨ Features

- **Interactive Map Canvas:** Click and pan around a beautifully styled Tolkien-inspired fantasy map.
- **Iconic Locations:** Detailed markers for places like The Shire, Rivendell, Moria, Mordor, Minas Tirith, Erebor, and more.
- **Search & Filters:** Instantly search for locations or filter them by category (e.g., *Realms of Men*, *Elven Realms*, *Dark Lands*).
- **Lore Modals:** Click any location marker or list item to read lore descriptions, key events, and famous quotes.
- **Fellowship Journey Path:** Toggleable route visualization tracking the path from Hobbiton to Mount Doom.
- **Tolkien Dark Fantasy UI:** Built with a parchment and dark-mode aesthetic using Tailwind CSS and Lucide icons.

## 🚀 Quick Start / Local Development

Since this project is built with vanilla HTML, CSS, and JavaScript, you don't need any complex build tools or node modules to run it!
